# Changelog

## v1.0.0

- Scan configured Feishu/Lark group chats via `lark-cli`.
- Detect file messages, task-like text, and prompt-like text.
- Send approval requests to a reviewer before execution.
- Execute approved runs by downloading files, creating tasks, or saving prompts.
- Store outputs in per-chat project folders for context management.
- Push execution results back to the source group.
- Support launchd-style recurring scan/check automation.
